How this demo works +

About every 48 hours, GitHub Actions checks access rules, collects the configured feed and official API metadata, removes matching canonical URLs, and publishes a snapshot. Your computer can be off.

TED coverage is the latest 100 matching urban-planning and landscape notices, including secondary CPV codes. Its ACTIVE search scope does not guarantee an open submission or eligibility. The competition feed covers recent entries, not the entire archive.

ASLA public-page metadata collection is restored. Landezine uses its robots-allowed public listing page because its RSS paths are blocked. Their reuse permissions remain unverified; copied descriptions and images are excluded. Other permission-dependent sources remain reference links. Missing participation status, eligibility, fees and budgets remain unverified.
